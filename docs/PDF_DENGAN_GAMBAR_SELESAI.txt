====================================================
  CARA KERJA GAMBAR DI PDF
====================================================

DOMPDF menggunakan public_path():

<img src="{{ public_path('images/logo-uprs.svg') }}" 
     alt="Logo" 
     class="logo">

public_path() returns:
C:\Laravel\Sistem_Inventory_UPRS_VI\public\images\logo-uprs.svg

DOMPDF reads file → Converts to PDF → Embeds image

SUPPORTED FORMATS:
✅ SVG (vector - best quality)
✅ PNG (raster - transparent bg)
✅ JPG/JPEG (raster - photos)
❌ GIF (not recommended)
❌ WebP (not supported)

====================================================
  TROUBLESHOOTING
====================================================

PROBLEM: Logo tidak muncul
SOLUTION:
1. Check file exists:
   ls -la public/images/logo-uprs.svg
2. Check permissions:
   chmod 644 public/images/logo-uprs.svg
3. Clear cache:
   php artisan view:clear
4. Restart server

PROBLEM: Logo pixelated/blur
SOLUTION:
✅ Use SVG (not PNG/JPG)
✅ SVG is vector = always sharp
✅ Check SVG viewBox attribute

PROBLEM: PDF generation error
SOLUTION:
1. Check DOMPDF version:
   composer show barryvdh/laravel-dompdf
2. Update if needed:
   composer update barryvdh/laravel-dompdf
3. Check public_path() returns correct path

PROBLEM: Colors tidak match
SOLUTION:
- Check HEX code: #4f46e5
- Use same HEX di semua tempat
- Test print preview
