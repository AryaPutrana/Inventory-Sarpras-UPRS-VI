[BUG-09] FOTO BARANG AKAN 404 DI SERVER — depends pada APP_URL & symlink
--------------------------------------------------------------------------------
 File    : config/filesystems.php (disk 'public')
 File    : public/storage  (Windows Junction, TIDAK tersimpan di git)
 File    : app/Models/Item.php:59-66

 MASALAH
     config/filesystems.php:
         'public' => [
             'driver' => 'local',
             'root' => storage_path('app/public'),
             'url' => env('APP_URL').'/storage',
             ...
         ]

   Dua titik gagal:

   (a) URL foto memakai env('APP_URL')
       .env saat ini:  APP_URL=http://localhost
       Meaning setiap foto menghasilkan URL seperti:
           http://localhost/storage/items/xxx.jpg
       Kalau di server APP_URL tidak diubah, semua foto akan mengarah ke
       localhost/server lain → 404 untuk semua user.

   (b) public/storage adalah Windows JUNCTION
       - Tidak tersimpan di git (.gitignore baris /public/storage)
       - Jika folder project di-COPY (zip, drag & drop, FTP) ke server,
         junction TIDAK ikut tersalin
       - Jellyka server Windows tanpa izin junction, storage:link gagal

   Gejala yang akan muncul: foto barang hilang / broken image,
  evenough.png placeholder öffentlich yang aman.

 BUKTI
   public/storage saat ini -> Junction -> storage/app/public
   Isi folder tersebut berisi 26 file foto barang milik user sungguhan,
   jadi fitur ini BENAR-BENAR dipakai.

 PERBAIKAN
   1. Pastikan .env di server:
        APP_URL=https://alamat-server-anda
        (atau http://192.168.x.x jika akses via LAN, tanpa garis miring akhir)

   2. Jalankan di server:
        php artisan storage:link

   3. Verifikasi:
        - php artisan storage:link
        - Cek muncul: "The [public/storage] link has been connected to
          [storage/app/public]"
        - Buka browser: http://alamat-server/storage/items/nama-file.jpg

   4. Untuk server Linux tanpa hak akses symlink, ganti caraerve foto:
        - Ubah disk 'public' -> root = public_path('storage/items')
        - Upload langsung ke folder publik (tanpa symlink)
        - ATAU tambahkan rewrite rule Apache/Nginx untuk folder storage

   5. Tambahkan ke setup.bat / setup-complete.bat agar otomatis dicek:

        php artisan storage:link
        if not exist public\storage (
            echo PERINGATAN: symlink storage gagal, foto tidak akan tampil!
        )

   6. Jalankan juga saat deploy:
        php artisan optimize:clear
        php artisan config:cache
