LANGKAH CEPAT UNTUK MEMULAI:

1. JALANKAN LARAGON
   - Buka aplikasi Laragon
   - Klik "Start All"
   - Tunggu hingga MySQL dan Apache berjalan (hijau)

2. BUAT DATABASE
   Buka Terminal/Command Prompt, jalankan:
   
   mysql -u root -p
   (tekan Enter saat diminta password)
   
   CREATE DATABASE sistem_inventory_uprs_vi;
   exit;

   ATAU via phpMyAdmin:
   - Klik "Database" di Laragon
   - Buat database: sistem_inventory_uprs_vi

3. SETUP DATABASE
   Di terminal project ini, jalankan:
   
   php artisan config:clear
   php artisan migrate:fresh
   php artisan db:seed

   Seeder akan membuat:
   ✅ 1 User: petugas@sarpras.com (password: password123)
   ✅ 6 Data Rusun: RABEK, UMEN, TIPAR, ALBO, CBT, KM2

4. JALANKAN SERVER
   
   php artisan serve

5. BUKA BROWSER
   
   http://127.0.0.1:8000

6. LOGIN
   Email: petugas@sarpras.com
   Password: password123

========================================
TROUBLESHOOTING
========================================

ERROR: Connection Refused
→ Laragon belum jalan, Start Laragon dulu

ERROR: Database not found
→ Buat database: sistem_inventory_uprs_vi

ERROR: Table not found
→ php artisan migrate:fresh
→ php artisan db:seed

ERROR: Login gagal
→ Cek email: petugas@sarpras.com
→ Cek password: password123
→ Pastikan seeder sudah jalan

Foto tidak muncul
→ php artisan storage:link

Tidak bisa akses dashboard
→ Login dulu di /login
