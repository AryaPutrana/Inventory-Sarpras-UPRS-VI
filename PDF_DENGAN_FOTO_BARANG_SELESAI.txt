====================================================
  FORMAT FOTO YANG DIDUKUNG
====================================================

DOMPDF mendukung:
✅ JPG / JPEG
✅ PNG (dengan transparency)
✅ GIF (basic)

NOT SUPPORTED:
❌ WebP
❌ SVG raster images
❌ HEIC / HEIF

RECOMMENDED:
- Format: JPG atau PNG
- Max size: 500KB per foto
- Resolution: 200x200px cukup (akan auto-resize)

====================================================
  PERFORMANCE & FILE SIZE
====================================================

FOTO IMPACT:
- 10 foto @ 50KB each = +500KB
- 100 foto @ 50KB each = +5MB

PDF SIZE ESTIMATE:
- No photos: ~60KB
- With 10 photos: ~600KB
- With 100 photos: ~5MB

GENERATION TIME:
- No photos: <1 second
- With 10 photos: 1-2 seconds
- With 100 photos: 3-5 seconds

RECOMMENDATION:
✅ Keep photos small (compress before upload)
✅ Thumbnail size (40x40) helps reduce PDF size
✅ Limit report to reasonable date range

====================================================
  TROUBLESHOOTING
====================================================

PROBLEM: Foto tidak muncul (blank)
SOLUTION:
1. Check file exists:
   ls -lh public/storage/items/
2. Check symlink:
   php artisan storage:link
3. Check photo column in database
4. Check file permissions

PROBLEM: Broken image icon (X)
SOLUTION:
1. Path salah → Check public_path()
2. File tidak ada → Upload ulang foto
3. Format tidak support → Convert to JPG

PROBLEM: PDF error saat generate
SOLUTION:
1. Check DOMPDF memory limit
2. Reduce photo quality
3. Limit number of rows per PDF
4. Use pagination

PROBLEM: Foto blur / pixelated
SOLUTION:
✅ Upload higher resolution (min 200x200)
✅ Use JPG quality 80-90%
✅ Don't over-compress

PROBLEM: PDF terlalu besar
SOLUTION:
1. Compress images before upload
2. Use JPG instead of PNG
3. Reduce image dimensions
4. Limit report date range

====================================================
  ADVANCED: COMPRESS PHOTOS
====================================================

Jika foto terlalu besar, compress dulu:

// In ItemController store/update:
$image = Image::make($request->file('photo'));
$image->resize(400, 400, function ($constraint) {
    $constraint->aspectRatio();
    $constraint->upsize();
});
$image->save(public_path('storage/' . $path), 80);
