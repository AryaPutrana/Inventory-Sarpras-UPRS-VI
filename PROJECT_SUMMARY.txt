   → Buka: http://localhost/phpmyadmin
   → Klik "New" atau "Databases"
   → Nama: sistem_inventory_uprs_vi
   → Collation: utf8mb4_unicode_ci
   → Klik "Create"

3. ⚙️ JALANKAN SETUP
   → Double-click: setup-complete.bat
   → Ikuti instruksi di layar
   → Script akan setup semuanya otomatis

4. 🌐 JALANKAN SERVER
   → Command Prompt/Terminal:
     cd C:\Laravel\Sistem_Inventory_UPRS_VI
     php artisan serve
   → Buka browser: http://localhost:8000

5. 🎉 SELESAI!
   → Sistem siap digunakan
   → Mulai tambah data barang
   → Coba semua fitur
