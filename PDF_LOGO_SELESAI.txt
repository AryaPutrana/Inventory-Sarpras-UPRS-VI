====================================================
  TROUBLESHOOTING
====================================================

PROBLEM: Logo tidak muncul
SOLUTION:
1. Check file: ls -lh public/images/logo-uprs.svg
2. Check path: public_path('images/logo-uprs.svg')
3. Clear cache: php artisan view:clear
4. Restart server

PROBLEM: PDF error saat generate
SOLUTION:
1. Check DOMPDF version
2. Update: composer update barryvdh/laravel-dompdf
3. Check public_path() correct

PROBLEM: Logo blur/pixelated
SOLUTION:
✅ Use SVG format (not PNG/JPG)
✅ SVG is vector = always sharp
