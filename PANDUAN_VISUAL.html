🏢 Sistem Inventory Sarpras UPRS VI

Panduan Setup & Instalasi

Tanggal: 29 September 2026

⚠️ Status Setup Saat Ini

  • PHP 8.1.10 sudah terinstall
  • Laravel Project sudah dibuat
  • Application Key sudah di-generate

❌ Yang masih perlu dilakukan: Start MySQL dan Setup Database

1 Start MySQL/MariaDB

Pilih sesuai software yang Anda gunakan:

📦 LARAGON (Recommended)

  1. Buka aplikasi Laragon (icon di desktop)
  2. Klik tombol "Start All"
  3. Tunggu hingga Apache & MySQL berwarna hijau
  4. MySQL akan running di port 3306

🔶 XAMPP

  1. Buka XAMPP Control Panel
  2. Klik tombol "Start" pada baris MySQL
  3. Tunggu hingga status berubah menjadi hijau

🟨 WAMP

  1. Klik icon WAMP di system tray
  2. Pilih "Start All Services"
  3. Tunggu hingga icon berwarna hijau

2 Buat Database

Pilih salah satu cara:

🌐 Cara 1: Menggunakan phpMyAdmin (PALING MUDAH)

  1. Buka browser
  2. Akses: http://localhost/phpmyadmin
  3. Klik tab "Databases" atau "Basis Data"
  4. Di kolom "Create database", masukkan nama:
sistem_inventory_uprs_vi
  1. Pilih Collation: utf8mb4_unicode_ci
  2. Klik tombol "Create" atau "Buat"

⌨️ Cara 2: MySQL Command Line

mysql -u root -p
CREATE DATABASE sistem_inventory_uprs_vi CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
EXIT;

📦 Cara 3: Laragon (Quick)

  1. Klik kanan icon Laragon di system tray
  2. MySQL → Create Database
  3. Nama: sistem_inventory_uprs_vi
  4. Klik OK

3 Jalankan Setup Otomatis

Setelah MySQL running dan database dibuat:

📁 Double-click file ini di folder project:
setup-complete.bat

Script akan otomatis:

  • Cek koneksi MySQL
  • Setup environment (.env)
  • Generate application key
  • Buat storage link
  • Jalankan migration (buat tabel)
  • Isi data rusun (6 data)
  • Clear cache

4 Jalankan Aplikasi

Setelah setup selesai, jalankan server:

cd C:\Laravel\Sistem_Inventory_UPRS_VI
php artisan serve

Kemudian buka browser dan akses:

🚀 http://localhost:8000
⚠️ TROUBLESHOOTING:
  • Error "Access denied" → Edit .env, ubah DB_PASSWORD sesuai password MySQL Anda
  • Error "Unknown database" → Database belum dibuat, ulangi Step 2
  • Port 8000 sudah digunakan → Gunakan: php artisan serve --port=8001
  • Foto tidak muncul → Jalankan: php artisan storage:link

✅ Setelah Setup Berhasil

Anda bisa langsung menggunakan sistem untuk:

  • Mengelola inventory barang dengan foto
  • Mencatat pengambilan barang
  • Membuat laporan berdasarkan tanggal & rusun
  • Export laporan ke PDF dan Excel
